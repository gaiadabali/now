What this shows

Enter a free-text query (runs the lexical + semantic generators against that text) or an article id (runs the same generators using the article's title/dek for lexical, and the article's own stored embedding for semantic kNN). Either way you get: raw per-generator hits, the RRF fusion, per-component scores, the hard-filter trace, fallback rung (when now_filters is importable), MMR/diversity status, and the full quality-score component breakdown.

Try any free-text query, or an article id from a `series_key` cluster (an annual "[Updated]" listicle, per ARCHITECTURE.md §8.A's series-dedup rule) to see the filter-trace panel actually remove a superseded sibling.
